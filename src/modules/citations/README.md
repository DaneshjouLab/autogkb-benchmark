# Citation Finding Experiments

This directory contains experiments for finding citations that support generated sentences.

## Running Experiments

The main entrypoint for all citation finding experiments is `run.py`.

### Finding Citations

You can find citations using different methods. The found citations will be saved in the `outputs/` directory.

**Syntax**:
```bash
python -m src.modules.citations.run --method <METHOD_NAME> --sentences-file <PATH_TO_SENTENCES.JSON> [OPTIONS]
```

**Available Methods**:
- `one_shot_citations`: A baseline method for finding citations.

**Examples**:

*   **Find citations from a sentences file**:
    ```bash
    # Make sure your OPENAI_API_KEY or ANTHROPIC_API_KEY is set in a .env file
    python -m src.modules.citations.run \
      --method one_shot_citations \
      --sentences-file ../sentence_generation/outputs/llm_sentence_gen_20240101_120000/sentences.json \
      --model gpt-4o \
      --prompt v1
    ```

*   **Limit the number of articles for a quick test**:
    ```bash
    python -m src.modules.citations.run \
      --method one_shot_citations \
      --sentences-file ../sentence_generation/outputs/llm_sentence_gen_20240101_120000/sentences.json \
      --max-articles 3
    ```

### Evaluating Citations

You can evaluate a previous citation finding run by pointing to the `citations.json` file generated by the process.

**Syntax**:
```bash
python -m src.modules.citations.run --eval <PATH_TO_CITATIONS.JSON>
```

**Example**:
```bash
python -m src.modules.citations.run --eval outputs/one_shot_citations_20240101_120000/citations.json
```

### Find and Evaluate in One Step

You can find and evaluate in a single command by adding the `--eval` flag.

**Syntax**:
```bash
python -m src.modules.citations.run --method <METHOD_NAME> --sentences-file <PATH_TO_SENTENCES.JSON> --eval
```

**Example**:
```bash
python -m src.modules.citations.run \
  --method one_shot_citations \
  --sentences-file ../sentence_generation/outputs/llm_sentence_gen_20240101_120000/sentences.json \
  --eval
```
