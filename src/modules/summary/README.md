# Summary Generation Experiments

This directory contains experiments for generating summaries from extracted sentences and citations.

## Running Experiments

The main entrypoint for all summary generation experiments is `run.py`.

### Generating Summaries

You can generate summaries using different methods. The generated summaries will be saved in the `outputs/` directory.

**Syntax**:
```bash
python -m src.modules.summary.run --method <METHOD_NAME> --sentences-file <PATH_TO_SENTENCES.JSON> [OPTIONS]
```

**Available Methods**:
- `basic_summary`: A baseline method for generating summaries.

**Examples**:

*   **Generate summaries from a sentences file**:
    ```bash
    # Make sure your OPENAI_API_KEY or ANTHROPIC_API_KEY is set in a .env file
    python -m src.modules.summary.run \
      --method basic_summary \
      --sentences-file ../sentence_generation/outputs/llm_sentence_gen_20240101_120000/sentences.json \
      --model gpt-4o \
      --prompt v1
    ```

*   **Include citations in the summary**:
    ```bash
    python -m src.modules.summary.run \
      --method basic_summary \
      --sentences-file ../sentence_generation/outputs/llm_sentence_gen_20240101_120000/sentences.json \
      --citations-file ../citations/outputs/citation_finder_20240101_120000/citations.json \
      --model claude-3-opus-20240229 \
      --prompt v2
    ```

*   **Limit the number of articles for a quick test**:
    ```bash
    python -m src.modules.summary.run \
      --method basic_summary \
      --sentences-file ../sentence_generation/outputs/llm_sentence_gen_20240101_120000/sentences.json \
      --max-articles 3
    ```

### Evaluating Summaries

You can evaluate a previous summary generation run by pointing to the `summary.json` file generated by the process.

**Syntax**:
```bash
python -m src.modules.summary.run --eval <PATH_TO_SUMMARY.JSON>
```

**Example**:
```bash
python -m src.modules.summary.run --eval outputs/basic_summary_20240101_120000/summary.json
```

### Generate and Evaluate in One Step

You can generate and evaluate in a single command by adding the `--eval` flag.

**Syntax**:
```bash
python -m src.modules.summary.run --method <METHOD_NAME> --sentences-file <PATH_TO_SENTENCES.JSON> --eval
```

**Example**:
```bash
python -m src.modules.summary.run \
  --method basic_summary \
  --sentences-file ../sentence_generation/outputs/llm_sentence_gen_20240101_120000/sentences.json \
  --eval
```
