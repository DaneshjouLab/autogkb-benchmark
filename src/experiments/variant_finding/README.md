# Variant Finding Experiments

This directory contains experiments for extracting variant mentions from full-text articles.

## Running Experiments

The main entrypoint for all variant finding experiments is `run.py`.

### Extracting Variants

You can extract variants using different methods. The extracted variants will be saved in the `outputs/` directory.

**Syntax**:
```bash
python -m src.experiments.variant_finding.run --method <METHOD_NAME> [OPTIONS]
```

**Available Methods**:
- `just_ask`: End-to-end variant extraction using an LLM.
- `regex_v1` to `regex_v5`: Iteratively improved regex-based methods.
- `regex_llm_filter`: Regex extraction followed by an LLM filtering step.
- `regex_term_norm`: Regex extraction with a term normalization step.
- `pubtator`: Variant extraction using the PubTator 3 API.

**Examples**:

*   **Run a regex-based method**:
    ```bash
    python -m src.experiments.variant_finding.run --method regex_v5
    ```

*   **Run an LLM-based method**:
    ```bash
    # Make sure your OPENAI_API_KEY or ANTHROPIC_API_KEY is set in a .env file
    python -m src.experiments.variant_finding.run --method just_ask --model claude-3-opus-20240229 --prompt v3
    ```

*   **Limit the number of articles for a quick test**:
    ```bash
    python -m src.experiments.variant_finding.run --method regex_v5 --max-articles 5
    ```

### Evaluating Extractions

You can evaluate a previous extraction run by pointing to the `variants.json` file generated by the extraction process. The evaluation results will be saved in the `results/` directory.

**Syntax**:
```bash
python -m src.experiments.variant_finding.run --eval <PATH_TO_VARIANTS.JSON>
```

**Example**:
```bash
python -m src.experiments.variant_finding.run --eval outputs/regex_v5_20240101_120000/variants.json
```

### Extract and Evaluate in One Step

You can extract and evaluate in a single command by adding the `--eval` flag.

**Syntax**:
```bash
python -m src.experiments.variant_finding.run --method <METHOD_NAME> --eval
```

**Example**:
```bash
python -m src.experiments.variant_finding.run --method regex_v5 --eval
```
