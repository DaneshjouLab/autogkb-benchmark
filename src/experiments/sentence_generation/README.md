# Sentence Generation Experiments

This directory contains experiments for generating sentences that describe the relationship between variants and other clinical terms.

## Running Experiments

The main entrypoint for all sentence generation experiments is `run.py`.

### Generating Sentences

You can generate sentences using different methods. The generated sentences will be saved in the `outputs/` directory.

**Syntax**:
```bash
python -m src.experiments.sentence_generation.run --method <METHOD_NAME> --variants-file <PATH_TO_VARIANTS.JSON> [OPTIONS]
```

**Available Methods**:
- `raw_sentence_ask`: A baseline method for generating sentences.
- `batch_judge_ask`: A method that batches sentences and uses an LLM to judge them.
- `llm_judge_ask`: A method that uses an LLM to both generate and judge sentences.

**Examples**:

*   **Generate sentences from a variants file**:
    ```bash
    # Make sure your OPENAI_API_KEY or ANTHROPIC_API_KEY is set in a .env file
    python -m src.experiments.sentence_generation.run \
      --method batch_judge_ask \
      --variants-file ../variant_finding/outputs/regex_v5_20240101_120000/variants.json \
      --model gpt-4o \
      --prompt v3
    ```

*   **Limit the number of articles for a quick test**:
    ```bash
    python -m src.experiments.sentence_generation.run \
      --method batch_judge_ask \
      --variants-file ../variant_finding/outputs/regex_v5_20240101_120000/variants.json \
      --max-articles 3
    ```

### Evaluating Sentences

You can evaluate a previous sentence generation run by pointing to the `sentences.json` file generated by the process.

**Syntax**:
```bash
python -m src.experiments.sentence_generation.run --eval <PATH_TO_SENTENCES.JSON>
```

**Example**:
```bash
python -m src.experiments.sentence_generation.run --eval outputs/batch_judge_ask_20240101_120000/sentences.json
```

### Generate and Evaluate in One Step

You can generate and evaluate in a single command by adding the `--eval` flag.

**Syntax**:
```bash
python -m src.experiments.sentence_generation.run --method <METHOD_NAME> --variants-file <PATH_TO_VARIANTS.JSON> --eval
```

**Example**:
```bash
python -m src.experiments.sentence_generation.run \
  --method batch_judge_ask \
  --variants-file ../variant_finding/outputs/regex_v5_20240101_120000/variants.json \
  --eval
```
